# AI Agent Sidang Skripsi

Kerangka awal proyek AI agent untuk membantu persiapan sidang skripsi.

- `backend/`: API dan modul RAG berbasis Python.
- `frontend/`: antarmuka aplikasi berbasis React.
- `backend/data/documents/`: lokasi dokumen sumber.
- `backend/data/chroma/`: lokasi penyimpanan data vektor Chroma.

Konfigurasi contoh backend tersedia di `backend/.env.example`.
